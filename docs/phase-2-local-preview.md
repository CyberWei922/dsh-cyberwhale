# 第二阶段本地预览

版本：`0.2.0-preview.1`。基于桌宠正式版 `0.1.4`，仅保存在本机；没有提交、推送、打标签或发布 npm。

## 怎么看效果

打开 DeepSeek Harness，进入 **设置 → 主题**。**设置 → 桌宠** 仍是单独一页。

1. 选择浅色、深色或跟随系统；深浅配色各自保留。
2. 选择预设，或更改强调色、背景色、文字色。
3. 背景先选择纯色、渐变或图片，只展示对应设置。纯色使用主题底色；渐变显示预设与遮罩；图片模式可以先选再上传 PNG、JPEG、WebP。上传后显示预览、更换／移除和布局选项。
4. 图片的「效果调整」和「从图片生成配色」默认折叠，展开后可调遮罩与模糊，或选择候选主色生成配套浅深配色。只展开取色不会改变配色。切换类型保留图片和渐变选择；移除图片后留在上传区域，窗口恢复主题底色。
5. 可打开「输入框磨砂玻璃」，返回聊天区查看；它是 Web 磨砂透光效果，保留较高遮罩，不使用原生液态玻璃。
6. 配色、字体、背景及特效修改后立即生效并自动保存，没有底部「保存／取消预览」栏。连续操作会串行保存最后的选择，关闭设置页后也会完成保存。
7. 每次进入主题页都会自动读取本机字体，界面字体和代码字体均可从下拉列表选择；选择「系统默认」清除覆盖。安装新字体后重新进入页面即可刷新列表，正常情况下不显示手动刷新按钮。读取失败时才显示「重新读取」及备用手动输入，不清空已有选择。

外观模式和正文字号由 Harness 官方设置管理，同样修改即保存。

在 **设置 → 桌宠 → 气泡液态玻璃** 可开启 Apple 原生气泡材质，默认关闭。需要 macOS 26 及以上；关闭后恢复普通气泡。该开关立即保存，与主题设置独立。
原生材质使用系统默认的中性 Liquid Glass，不添加插件染色、HTML 底色或额外描边；HTML 仅呈现文字。气泡仍为点击穿透的装饰，不接管输入。

「启用外观美化」关闭后恢复官方或此前主题插件的配色。桌宠设置独立，不受影响。
「减少透明效果」保留配色与字体，隐藏图片、渐变和输入框特效。
桌宠待机时保留眨眼与鼠标注视，不自动冒出闲聊气泡；任务进度、打招呼、完成及失败提示仍保留。

## 本版范围

| 功能 | 本地预览 |
|---|---|
| 独立主题页 | 已实现，使用 Harness 设置导航和官方按钮、开关、模式控件 |
| 配色预设 | 27 个选项：浅色 10 个、深色 17 个；Codex 默认及 15 组开源同款主题，另有蓝鲸浅深原创。具体版本和来源见 [主题预设来源](theme-presets.md) |
| 自选颜色 | 三种基础色，自动派生表面、文字、强调、选区与边界；按实际控件背景修正低对比文字与开关、选中边界 |
| 字体 | 自动读取本机字体家族并下拉选择；读取失败时可手动输入，保留系统回退；正文字号使用官方接口 |
| 背景 | 整个 Web 窗口底层；纯色、三套渐变、本地静态图片，共用一张深浅背景 |
| 图片处理 | 原图最多 25 MB / 5000 万像素；解码后长边最多 2048，转换为 JPEG，最多 2 MB |
| 图片布局 | 按窗口尺寸填充 / 适应，居中 / 顶部 / 底部，遮罩及模糊；侧栏收放及拖动不改变图片尺寸或位置 |
| 背景设置展示 | 按当前类型展示；空图片模式显示上传区域，已上传图片的效果与取色按需展开；切换类型保留已有选择 |
| 左侧磨砂 | 背景开启时，侧栏以半透明底色与 Web backdrop-filter 模糊底层图片；不替换官方侧栏组件 |
| 图片取色 | 最多 4096 个采样像素，Material Color Utilities 0.4.0 量化及评分，候选主色生成浅深配色 |
| 输入框磨砂玻璃 | 可关闭的 Web backdrop-filter，保留输入与发送控件；不是 Apple 原生材质 |
| 气泡液态玻璃 | 桌宠页独立开关，默认关闭；自有 Electron 窗口内插入 Apple `NSGlassEffectView`，位置、隐藏、缩放和系统外观同步 |
| 多窗口 | 每 10 秒读取配置，隐藏窗口暂停；过期修改拒绝覆盖最新配置，恢复已保存配置并提示重新选择 |
| 配置 | 独立保存、串行原子写入；图片使用资源 ID，经过官方连接鉴权读取 |

背景关闭时侧栏沿用 Harness 的原生磨砂材质。背景开启时，侧栏使用页面内磨砂采样图片；本插件不修改原生窗口创建参数，新增效果不宣称为 Apple 原生材质。
文本配色和选中强调色随主题变化；壁纸层挂载在三栏共同框架下，不进入编辑器或占用官方 overlay 插槽。图片按整个窗口尺寸定位，侧栏收起后背景继续保持原来的位置及大小。
聊天正文背景透明，统一使用可调的壁纸遮罩保持可读性；代码块和输入框保留各自的阅读表面。

## 目前限制

- **Harness 主窗口的原生 Liquid Glass 暂未实现**：当前没有原生视图接入接口；输入框保留 Web 磨砂。桌宠气泡属于我们自己的窗口，已单独接入原生 Liquid Glass。本版没有修改 Harness 应用或安装包。
- 气泡原生组件包含 macOS arm64 与 x64 的 Node-API 预构建文件。Apple Silicon 在 macOS 27 / Electron 43.4.1 验证；Intel 已构建，尚未真机验证。Windows、Linux、旧版 macOS 及系统降低透明度或增强对比度时使用普通气泡。
- 界面参考 Codex Appearance 的双卡片和公开基础色值，未复制 Codex Desktop 源码。公开 `openai/codex` 仓库为 Apache-2.0，主要是 CLI。
- 壁纸覆盖当前 Web 窗口底层，左侧与聊天区共享同一张图片。代码块、输入框、菜单和工具面板可保留自身阅读表面；嵌入的浏览器/文档、系统弹窗及其他原生窗口不会因此变成透明背景。
- 终端字体、语法高亮的全部颜色、独立 UI / 代码字号、自定义预设命名与导入导出留待后续。
- 图片取色为显式选择候选主色，不自动随壁纸变化；首版在主线程用小图执行，尚未加入 Worker。
- 每种模式不能分别保存不同壁纸；没有视频、轮播或远程下载。
- 只在 macOS 的 Harness `0.2.0-rc.2` 实机检查。Windows 使用共用 Web 接口，但新美化功能尚未做 Windows 真机验收。
- 客户端声明主题服务依赖，当前预览需完整的官方 Desktop 组合包。其他精简 Harness 组合需另验。
- 与其他主题插件同时启用时，遵循官方后写入覆盖规则，暂不自动合并主题。

## 本机安装方式

开发目录已改名为 `/Users/wei/Projects/dsh-cyberwhale`，Harness Desktop 的插件链接已指向新目录，版本仍为 `0.2.0-preview.1`。
已有 profile 安装记录仍使用 `link:/Users/wei/Projects/dsh-deskpet`；旧目录名现为指向新目录的兼容链接，以便运行中的 Harness 和后续依赖恢复继续解析到同一份代码。若需移除兼容链接，先完整退出 Harness，并通过官方插件管理器把安装来源更新为新目录。
这次无需 npm 发布或等待 24 小时。以后修改客户端源码仍须重新构建，并刷新或重启 Harness 才加载新客户端；宿主变更建议重启。

用户数据在 `$DSH_HOME/dsh-cyberwhale/`：

- `settings.json`：原有桌宠配置。
- `appearance.json`：主题配置与修订号。
- `wallpapers/`：导入后复制的静态图片；不依赖原图路径。

本次安装前的桌宠与 profile 配置备份位于本项目 `output/appearance-preview/backup/`。
如需回到发布版，先完整退出 Harness，再使用官方插件管理器将本地链接换为 `dsh-cyberwhale@0.1.4`；不要在应用运行时直接覆盖 profile。

## 验证记录

原有测试加接口回归共 614 项通过，另有主题专项断言通过。自动检查覆盖主题颜色对比度、配置归一化、独立保存、并发修订冲突、壁纸内容及路径校验、鉴权资源读取，以及背景层不会进入编辑器。本次自动保存改动通过客户端 94 项回归、主题专项及新增自动保存专项，覆盖快速修改合并、关页继续保存、旧轮询响应、写入失败恢复与多窗口冲突。测试输出保存在 `output/appearance-preview/`。

macOS 实机检查包括：两个独立设置页、模式切换、Mocha 配色、渐变、PNG 上传与候选主色、壁纸资源读取、磨砂输入框编辑和清空。重启后配色、图片背景与磨砂开关恢复成功；关闭美化能撤销背景和颜色。

本次自动保存改动已确认底部保存／取消栏消失，改动颜色后直接写入本机配置，关闭并重新打开设置后保留。后续桌面界面验收由维护者自行进行，助手只执行构建和代码检查。

整窗壁纸新增无界面浏览器专项检查，覆盖 Mac/Windows 的浅深模式布局、侧栏收起/展开/拖动时背景几何及像素不变、窗口尺寸调整、侧栏磨砂、嵌套正文底色透明、控件点击与输入、减少透明、外壳重建和卸载资源释放。该检查使用独立测试页面，实际 Harness 界面效果由维护者验收。

选中态配色补齐了官方通用设置的选中外观卡片、权限选择器和字号框所用表面，以及选区、按钮悬停和关闭状态开关的颜色。27 个预设、图片取色及中灰等自定义颜色均检查实际表面上的文字对比度；按钮悬停保持配套前景色，不再套用官方默认黑白反转。`tools/test-appearance-controls.mjs` 在独立无界面页面读取本机 Harness 的官方样式，27 套配色的选中卡片、权限选择器、字号、按钮悬停与开关检查通过；没有打开或操作维护者的桌面界面。该专项需要 Playwright，可通过 `DSH_TEST_BROWSER_MODULE` 指定模块，`DSH_TEST_ASAR` 指定其他位置的 Harness 安装包。

背景展示调整通过客户端 112 项与宿主 102 项检查，新增回归覆盖类型切换、空图片入口、默认折叠、明确选择主色后才应用配色，以及移除图片后继续留在图片模式；主题存储检查覆盖切换类型保留图片、渐变和布局参数，以及空图片模式保存后重新读取。

渐变绘制修正了包含底色的预设被误写入 `background-image`、导致浏览器忽略整个渐变的问题。现在以完整背景样式绘制预设底色、渐变和阅读遮罩；图片的布局与模糊参数只在图片模式生效。无界面背景检查覆盖三种渐变在浅深模式和 Mac/Windows 布局下的样式接受、底色及实际像素变化，同时保留图片、侧栏与卸载回归检查。

开发路线中的整项跨平台和性能验收仍需继续，本版是供选择视觉方向的本地原型。

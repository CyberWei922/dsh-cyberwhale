# CyberWhale 1.0 正式版

CyberWhale 为 DeepSeek Harness 提供 macOS 与 Windows 双端视觉本地化，以及主题、壁纸、字体设置和可选蓝鲸桌宠。从 1.0 开始，后续版本以这一产品范围继续迭代。

## 双端视觉本地化

- macOS 设置页参考系统设置：圆角分组、细分隔线、小型开关和磨砂侧栏。
- Windows 设置页参考 WinUI 3：导航强调色指示条、设置卡片、小圆角控件和 Mica 风格底色。
- 自动识别客户端系统，沿用 Harness 的控件行为与设置入口。两套界面均已由维护者确认日常使用正常。

## 主题与个性化

- 27 个配色选项，浅色 10 个、深色 17 个；支持自定义强调色、背景色和文字色。
- 纯色、三套渐变和本地图片背景，支持布局、遮罩和图片模糊。
- 从图片提取候选主色，选择后生成配套浅深配色。
- 本机字体选择，界面字体和代码字体分别设置；可选输入框磨砂和减少透明效果。
- 修改立即生效并自动保存，外观美化与桌宠独立控制。

## 蓝鲸桌宠

保留任务状态动画、进度气泡、拖动、鼠标注视、显示大小和位置记忆。macOS 26+ 可选原生气泡 Liquid Glass；其他支持平台使用普通气泡。

## 安装与升级

在 Harness 插件页添加 `dsh-cyberwhale@1.0.0`，也可使用本 Release 的 `.tgz` 附件。旧版用户先卸载插件，再指定新版本安装，并完全退出、重新打开 Harness。

进入「设置 → 主题」开启外观美化；桌宠在「设置 → 桌宠」单独控制，只使用外观功能可跳过桌宠运行时准备。

验证基线为 Harness Desktop 0.2.0-rc.2，支持 macOS 和 Windows 11 x64。平台设置样式、侧栏和输入框材质使用 Web 视觉模拟；macOS 桌宠气泡 Liquid Glass 使用原生材质。

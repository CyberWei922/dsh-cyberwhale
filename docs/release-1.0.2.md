# CyberWhale 1.0.2：修复 Windows 设置交互与背景切换

改进 Windows 设置界面的 WinUI 3 样式，修复下拉框滚动、弹层裁剪与背景切换问题。

- Windows 字体、主题预设、图片布局和桌宠大小使用自绘 WinUI 下拉框，保留键盘选择与无障碍语义。
- 下拉弹层在设置面板内独立滚动，所有主题选项均可到达；支持 Home / End、方向键、输入前缀查找、Enter 选择，以及 Escape、Tab 和外部点击关闭。
- Windows 导航、开关、设置行和下拉框的浅深色样式对齐微软 Fluent / WinUI 3 token。
- 切换纯色、渐变和图片背景时保留已上传图片及效果参数；未上传图片时也可选择图片模式并直接上传。
- 系统的“减少透明效果”不再隐藏用户设置的静态壁纸；插件自身的“减少透明效果”仍使用实色表面。
- macOS 保留原有系统下拉框和分段控件；修复 Windows 侧栏留白时限定平台作用范围。

验证：构建与完整自动化测试通过；17 项隔离浏览器交互检查覆盖浅深色、键盘、滚轮、缩放、窄窗口、macOS 控件保留与旧浏览器回退。Windows 实机验收由维护者确认通过。

在 Harness 插件页安装 `dsh-cyberwhale@1.0.2`，或使用本 Release 的 `.tgz` 附件。旧版用户先卸载插件，再指定新版本安装，并完全退出、重新打开 Harness。

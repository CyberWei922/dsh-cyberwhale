# CyberWhale 1.0.4：适配 Harness 0.2.2，并给输入框下方的状态行加磨砂

Harness Desktop `0.2.2-rc.1` 重排了设置弹窗的 DOM、调整了主题字号接口；本版把插件的结构锚点从「兄弟顺序」改为官方 `data-slot` 语义锚点，并补上输入框下方状态行的可读性处理。

## 适配 Harness 0.2.2

- 设置面板：窗口标题、导航、动作栏、内容区在 0.2.2 变成了 `<nav>` 的同级节点，插件改用 `settings.header` / `settings.close` / `settings.section` 定位，面板改为显式两列网格，侧栏磨砂覆盖整列（含标题行），内容区独占滚动。
- 自定义背景：主列在 0.2.2 多了一层包装元素，透明层选择器改为后代匹配并清掉包装层，壁纸重新铺满整个窗口而不只是侧栏。
- 主题字号：「正文字号 +/−」适配 `theme.setFontSize(role, px)` 与 `fontSizes.text`，点击后数值正确变化。
- Windows 样式层同步改用同一套锚点，避免 0.2.2 下右侧内容列背景打到动作栏上。
- 更新 `verify:mac-settings-render` 的渲染夹具到 0.2.2 面板结构，后续升级可继续用它验收。

## 输入框下方状态行

「缓存命中 · tok/s」那一行原本压在滚动内容上，开了壁纸后文字会从它下面穿过去。

- 在输入框那一层加一块与输入框等宽的磨砂：宽度用官方 `--dsh-composer-side-clearance` 内缩，左右与输入框严格对齐。
- 只做模糊、几乎不加底色（8%），壁纸颜色保留；模糊层收在 composer 盒子内，不会给滚动区增加高度，滚到底时输入框仍贴底。
- 关闭外观美化、选择纯色背景或开启「减少透明效果」时保持官方原样。

验证：`npm test` 全绿（102 / 132 / 80 / 80 / 66 / 66 / 90 / 37）；在隔离的 0.2.2 profile 中实测设置页布局、字号步进、壁纸透明层与滚动贴底行为，并用 Electron 真实合成核对磨砂的宽度与位置。

在 Harness 插件页安装 `dsh-cyberwhale@1.0.4`，或使用本 Release 的 `.tgz` 附件。旧版用户先卸载插件，再指定新版本安装，并完全退出、重新打开 Harness。

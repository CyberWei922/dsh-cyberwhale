## 角色尺寸（硬性，务必逐条遵守）

单元格是 192 × 208。角色**不允许画满整格**，必须落在下面的安全区内：

| 约束 | 数值 |
|---|---|
| 角色最大宽度 | **≤ 168 px** |
| 角色最大高度 | **≤ 184 px** |
| 脚底 / 重心线 | 距格子底边 **12 px**（即格内 `y = 196`） |
| 水平轴线 | 格内 `x = 96` |
| 角色允许出现的范围 | `x ∈ [12, 180]`、`y ∈ [12, 196]` |

**三条同时成立：**

1. **所有帧用同一个比例** —— 不能有的帧大、有的帧小。以最大的那个动作定比例，
   其余动作按同样比例画。（播放时忽大忽小是最刺眼的问题）
2. **脚底都落在 `y = 196`** —— `jumping` 行允许整体上移，但起跳前和落地后要回到这条线。
3. **四周留出透明余量** —— 即使某个动作本身就小，也不要放大去填满格子。

> 「不要碰到边界」这句话单独说是没法执行的：1px 和 60px 都叫"没碰到"。
> 请按上面的数字来。

## 第 0 行 · `idle` 待机

整体：安静的呼吸与眨眼循环，几乎不动。

| 帧 | 看哪里 | 做什么 | 情绪 |
|---|---|---|---|
| 0-0 | 正前方，略微下垂（像发呆） | 完全静止，最放松的站姿 | 平静 |
| 0-1 | 同上 | 身体轻轻上浮（吸气），尾巴微抬 | 平静 |
| 0-2 | 同上 | 身体落回（呼气），尾巴微落 | 平静 |
| 0-3 | 同上 | 眨眼 | 平静 |
| 0-4 | 同上 | 睁眼，身体极轻微左右晃 | 平静 |
| 0-5 | 同上 | 回到静止，尾巴位置与 0-0 略不同 | 平静 |

> 列 6、7 留空。
> 帧 0-0 会被单独拿来当"静止展示帧"，所以它必须是一个完整、独立的造型。

## 第 1 行 · `running-right` 向右移动

整体：被拖拽着向右移动。**视线始终朝右**（前进方向），身体有交替的推进节奏。

| 帧 | 看哪里 | 做什么 | 情绪 |
|---|---|---|---|
| 1-0 | 右 | 身体回中位，尾巴甩向一侧 | 有劲 |
| 1-1 | 右 | 身体右倾，尾巴甩向另一侧 | 有劲 |
| 1-2 | 右 | 身体略微上浮，肢体一前一后 | 有劲 |
| 1-3 | 右 | 回中位，与 1-0 相反的相位 | 有劲 |
| 1-4 | 右 | 身体右倾，与 1-1 同相、幅度略不同 | 有劲 |
| 1-5 | 右 | 上浮，肢体前后交换 | 有劲 |
| 1-6 | 右 | 接近中位 | 有劲 |
| 1-7 | 右 | 姿态最舒展的收尾，适合停留 | 有劲 |

> 8 帧要能看出**交替的步态**，不能是同一个姿势重复 8 次。

---

## 第 2 行 · `running-left` 向左移动

整体：与第 1 行对称，**视线始终朝左**。

- **优先做法**：把第 1 行整行水平镜像（角色左右对称、且没有手持道具时适用）
- **否则**：照第 1 行的帧序重新做一版**朝左**的

> 镜像时**帧顺序不能倒转**（是镜像，不是倒放）。
> 角色若持有道具，必须重新做，不能让道具换到错误的手上。

## 第 4 行 · `jumping` 跳跃

整体：一次完整跳跃 —— 蓄力、起跳、最高点、下落、落地。**视线跟随身体上下。**

| 帧 | 看哪里 | 做什么 | 情绪 |
|---|---|---|---|
| 4-0 | 略微向上 | 身体下压收缩，蓄力 | 期待 |
| 4-1 | 向上 | 蹬起，身体向上拉伸 | 兴奋 |
| 4-2 | 向上 | 到达最高点，姿态最舒展 | 兴奋 |
| 4-3 | 向下 | 开始下落，身体略微前倾 | 兴奋 |
| 4-4 | 前下方 | 落地，身体轻微压扁缓冲 | 满足 |

> 列 5–7 留空。
> 这一行是**唯一**允许身体在格内上下移动位置的行。

## 第 5 行 · `failed` 出错 / 沮丧

整体：从正常逐渐垮下去，再慢慢缓回来。**视线主要向下。**

| 帧 | 看哪里 | 做什么 | 情绪 |
|---|---|---|---|
| 5-0 | 正前方 | 正常站姿，眼睛开始出现变化 | 有点不对劲 |
| 5-1 | 向下 | 身体下沉，头低下去 | 失落 |
| 5-2 | 向下 | 眼睛变成难过/闭合状，身体更低 | 难过 |
| 5-3 | 向下 | 最低点，整体萎靡 | 沮丧 |
| 5-4 | 向下 | 保持低落，身体轻微摇晃 | 沮丧 |
| 5-5 | 向下 | 身体开始回升 | 缓和 |
| 5-6 | 前下方 | 抬起来一点 | 缓和 |
| 5-7 | 正前方 | 回到接近正常，但还带着倦意 | 疲惫 |

> 允许贴在身体上的眼泪或贴合轮廓的烟雾团；不要飘浮、不要分离的符号或泪滴。

| 帧 | 看哪里 | 做什么 | 情绪 |

| 6-0 | 向上（看向画面外） | 抬头，身体前倾 | 期待 |
| 6-1 | 向上 | 头再抬高一点，眼睛睁大 | 期待 |
| 6-2 | 向上 | 身体轻微左右晃，像在催促 | 着急 |
| 6-3 | 向上（歪头） | 歪头 | 好奇、期待 |
| 6-4 | 向上 | 身体回正，头仍抬着 | 期待 |

整体：**只动眼睛和头部，身体基本不动。** 8 帧连起来是从正上顺时针转到"下偏右"的一条连续视线轨迹。

| 帧 | 看哪里（角度） | 做什么 | 情绪 |
|---|---|---|---|
| 9-0 | **000° 正上**（12 点钟） | 眼睛向上看，头微微上扬 | 中性 |
| 9-1 | 022.5° 上偏右 | 视线右移一点 | 中性 |
| 9-2 | 045° 右上 | 头开始向右转 | 中性 |
| 9-3 | 067.5° 右偏上 | 视线接近水平右 | 中性 |
| 9-4 | **090° 正右** | 眼睛看右，头微转向右 | 中性 |
| 9-5 | 112.5° 右偏下 | 视线开始向下 | 中性 |
| 9-6 | 135° 右下 | 头略低 | 中性 |

## 交付要求

交付方式有**两种，任选其一**。方式 A 更省事，且不需要对齐网格。

### 方式 A（推荐）：透明散帧

- **一帧一张 PNG**，带 alpha 通道，背景完全透明
- **尺寸不限** —— 每张可以不一样大，但角色在画布里要**完整、不贴边**（四周留些余量）
- 按动作分子目录，文件名用序号：

```
frames/
├── idle/0.png 1.png 2.png 3.png 4.png 5.png
├── running-right/0.png ... 7.png
├── running-left/0.png ... 7.png
├── waving/0.png ... 3.png
├── jumping/0.png ... 4.png
├── failed/0.png ... 7.png
├── waiting/0.png ... 5.png
├── running/0.png ... 5.png
├── review/0.png ... 5.png
├── look-a/0.png ... 7.png        # 注视方向 0°–157.5°
└── look-b/0.png ... 7.png        # 注视方向 180°–337.5°
```

对齐格子、统一缩放、统一重心这三件事**由程序完成**：

```bash
node tools/assemble-atlas.mjs frames/ --out assets/spritesheet.png
```

它还会自动检查每帧是否贴边、是否缺帧，并直接告诉你**哪一帧需要重画**。

**用这种方式时不需要品红背景** —— 直接输出透明 PNG 即可，省掉抠色环节和边缘残留。

### 方式 B：已对齐网格的横向长条

只有在无法输出透明 PNG 时才用这种方式。

- 每批次一张横向长条：宽 = `192 × 帧数`，高 = `208`
- 留空的格子也照常占位
- 角色位置按上面的「角色尺寸」小节
- 重心高度在所有帧之间保持一致（`jumping` 行除外）

**背景（仅方式 B）**
- 统一纯色品红 `#FF00FF`
- 角色身上不要出现接近品红的颜色
- 背景要平坦：无渐变、无纹理

拼装时用 `--key FF00FF` 抠掉背景：

```bash
node tools/assemble-atlas.mjs frames/ --key FF00FF --out assets/spritesheet.png
```

**不要出现**（会破坏透明抠图）
- 投影、落地阴影、地面
- 独立的星星、闪光、速度线、动作残影、飘浮符号
- 文字、帧号、网格线

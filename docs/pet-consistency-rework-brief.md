# 形象一致性返工清单 · 给绘图端

> **一句话**：问题不在位置对齐，而在**每一帧的角色细节都不一样**（裙摆荷叶边数量、围裙小鲸鱼位置、刘海走向、袜口高度、表情结构……）。动画播放时这些差异会被放大成"穿帮"。
>
> **修法不是重画，是"拿一张基准图逐帧做最小编辑"。** 方法不对，重画一百遍也一样。

---

## 1. 问题定位（先看证据，再动手）

把 gaze 行的 8 帧对齐后逐像素求差，得出两件事：

**① 不是配色问题。** 把每帧的配色统计迁移到基准帧，帧间色差只降了 **0~3%**：

```
gaze-a   原始色差 26.8 → 迁移后 26.8   降幅 0%
gaze-b   原始色差 30.6 → 迁移后 29.9   降幅 2%
```

**② 是线条结构问题。** 差异热力图上**所有轮廓线都发亮** —— 即使把位置对齐，线条本身也对不上。

放大 2 倍看围裙区域，逐帧差异包括：

- 荷叶边的**褶皱数量**不同
- 围裙的**形状与宽窄**不同
- 围裙上**小鲸鱼图案的位置、大小、朝向**不同
- **袜口粉色边的高度**不同
- **袖口**形状不同
- 脸在头部里的**位置**有偏移
- **刘海发丝走向**不同
- **眉毛、眼睛形状、嘴型**每帧都在变（有个别帧甚至变成了完全不同的表情）

**这些是"重画出来的不同角色"，不是"同一个角色的不同姿态"。**

---

## 2. 铁律

### ❌ 绝对不要这样做

```
"生成 8 张鲸鱼女孩看向不同方向的图"
```

一次生成多张独立图 = 每张都从零画 = **细节必然漂**。这就是问题来源。

### ✅ 必须这样做

```
拿【同一张基准图】→ 一次只改【一帧】→ 用【最小编辑】的措辞
```

**每一帧都必须以同一张基准图为起点**，而不是以上一帧为起点（否则误差会累积）。

## 5. 提示词模板（直接复制）

给 GPT 类绘图模型时，**附上基准帧图片**，然后发这段：

```
【参考图】附件是基准帧。请把它作为唯一的形象依据。

【任务】把这张图改成「眼睛看向 <方向>」的版本。

【必须像素级保持一致 —— 一律不许改动】
· 服装：女仆装的全部结构与褶皱、围裙形状与荷叶边数量、领结与蓝宝石、
  腰带、袖口、裙摆、长袜、鞋子
· 围裙上的小鲸鱼图案：位置、大小、朝向
· 头发：发量、发丝走向、刘海分缝、发梢位置、蓝色渐变
· 头饰：女仆头饰的褶皱数量与形状、右侧蓝色蝴蝶结的大小与位置
· 脸型、肤色、脸颊腮红、耳朵（鱼鳍）
· 整体配色、线条粗细、描边风格、光影与高光位置
· 角色在画布中的位置和大小（不许移动、不许缩放）

【只允许改这两处】
· 瞳孔朝向（眼珠转向 <方向>）
· 头部倾斜（最多 5~8 度，身体几乎不动）

【输出】
· 512×560，透明背景 PNG
· 与参考图完全相同的构图与边距
```

**关键措辞**：
- 「**像素级保持一致**」「**一律不许改动**」比「尽量保持」有效得多
- 明确列出**不许变的元素清单** —— 模型不知道你在意什么，你必须逐个点名
- 明确说出**只允许改的两处** —— 给它一个封闭的改动范围

## 7. 禁止清单

- ❌ 一次生成多张
- ❌ 以上一帧为起点改（误差会累积）—— **永远从同一张基准图出发**
- ❌ 改变角色大小或画布位置
- ❌ 改变配色、线条粗细、描边风格
- ❌ 整体旋转角色来表达方向
- ❌ 改完输出成有背景的图（必须透明底）
- ❌ 尺寸不是 512×560

---

## 8. 自检（交付前逐条过）

- [ ] 新帧与基准图**并排放在一起**，除眼睛/头部倾斜外**看不出差别**
- [ ] 把新帧和基准图来回切换，**服装区域不闪**
- [ ] 围裙小鲸鱼的位置**完全重合**
- [ ] 荷叶边的褶皱**数量一致**
- [ ] 透明背景，512×560
- [ ] 眼睛确实看向了目标角度

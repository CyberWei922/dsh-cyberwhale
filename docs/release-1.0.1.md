# CyberWhale 1.0.1：更新插件名称与介绍

修复 Harness 安装及插件详情中仍显示「大肥鱼桌宠」和早期桌宠介绍的问题。

- 中文插件名称更新为 **Harness 美化与桌宠**；英文名称更新为 **Harness Appearance & Desk Pet**。
- 中英文介绍覆盖 macOS 与 Windows 风格界面、主题配色、壁纸、字体设置，以及可独立开关的蓝鲸桌宠。
- npm 描述与 README 安装指引同步更新。
- 发布流程使用当前版本对应的发布说明。

插件包名仍为 `dsh-cyberwhale`。在 Harness 插件页安装 `dsh-cyberwhale@1.0.1`，或使用本 Release 的 `.tgz` 附件。旧版用户先卸载插件，再指定新版本安装，并完全退出、重新打开 Harness，以刷新插件卡片名称和介绍。

本次为名称与介绍修正，沿用 1.0.0 的双端界面和功能；完整功能说明见 [1.0 正式版](https://github.com/CyberWei922/dsh-cyberwhale/releases/tag/v1.0.0)。
